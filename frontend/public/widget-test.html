Sitio web de prueba

Esta página simula el sitio web de Galana Clínica Dental.
El botón azul abajo a la derecha es el widget de molaris.ai.

Para integrarlo en cualquier sitio solo se necesita pegar este código:

<script src="http://localhost:3000/widget.js" data-clinic="galana" data-color="#0891B2" ></script>
